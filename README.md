# Queensgambit

i want to create a chess game with the ideas of the duolingo chess it should be online and offline when a player is losing or did a bad move (everyone should have his own charakter) the charakter should make a sad face and if a player makes a good move or has many point (like getting the other guys Queen) and , for the theme of the board, the default should be classic black and eggshell white then the user should be able to change that theme to other colours such as black and red, white and green, mixed colours or different types of stones. 

The game is playable on the web
it is multiplayer
it has engaging animations.
the chess pieces can also be customised in the settings menu.
